# Scalp Lab - бэктесты закономерностей на исторических данных

Поиск устойчивых закономерностей для быстрых сделок (скальпинг) на Binance USDT-M Futures.

## Как это работает
- **Данные**: официальные архивы https://data.binance.vision (klines), 20 ликвидных пар, таймфреймы 1m/5m/15m.
- **Без подгонок**: walk-forward - параметры подбираются на одном окне, результат считается на следующем (out-of-sample). Комиссии (0.05%) и проскальзывание учтены.
- **Множественные тесты**: паттерны проходят поправку Бенджамини-Хохберга (FDR 5%).
- **Стратегии**: ema_cross, bollinger_reversion, donchian, volume_surge, vwap_reversion.
- **Сканер паттернов**: всплески объема, аномальные диапазоны, длинные тени, серии баров -> форвардные доходности с t-статистикой.

## Воркеры
- GitHub Actions запускается каждые 6 часов, обрабатывает очередь задач 40 минут, коммитит результаты и прогресс (потом "выключается" до следующего запуска).
- Полная очередь: 360 задач (20 пар x 3 TF x (5 стратегий + 1 скан)).
- Результаты: `results/backtest/*.json`, `results/scan/*.json`
- Отчет: `reports/REPORT.md` (обновляется ежедневно), лидерборд: `reports/leaderboard.csv`

## Локальный запуск
```
cd scalp-lab
pip install -r requirements.txt
python queue_builder.py
python worker.py --budget 10
python reporter.py
```
